Postprozessoren

QGIS zeigt direkt Tiefenmittelwerte an und benötigt keine zusätzliche Software. Dreidimensionale Ergebnisse werden am besten mit einem dedizierten Visualisierungsprogramm angezeigt. aXqua arbeitet mit zwei von ihnen, und beide sind optional.

Beide Programme werden von einem Assistenten installiert. Auf einem Computer, auf dem OpenFOAM läuft, installiert der OpenFOAM Assistent sie zusammen mit dem Solver (OpenFOAM). Auf einem Computer, der nur TELEMAC ausführt, klicken Sie auf Install ParaView and VisIt… in der Box Simulation & postprocessing software der Registerkarte Configuration. Der Assistent hat zwei Einstellungen, den Installationsordner von VisIt und die Auswahl der Programme und funktioniert wie für die Simulationssoftware beschrieben (Simulationssoftware). Es ist auf Debian 12, Ubuntu 22.04, Ubuntu 24.04 und Linux Mint 22 verfügbar. Die gleiche Installation wird in einem Terminal mit axqua install start postprocessors gestartet.

Auswahl der Programme. ParaView and VisIt ist der Standard. ParaView only lässt VisIt aus: Es wird nichts heruntergeladen und der Assistent gibt die ParaView des Betriebssystems in das Profil ein. Der OpenFOAM Assistent bietet die gleiche Auswahl und zusätzlich None. In einem Terminal lässt die Option --no-visit VisIt aus. aXqua empfiehlt die Installation von VisIt, da es seine vordefinierten dreidimensionalen Figuren mit VisIt (VisIt) darstellt. Ohne VisIt sind diese Zahlen nicht verfügbar und dreidimensionale Ergebnisse werden interaktiv in ParaView inspiziert. VisIt kann jederzeit danach mit dem gleichen Assistent installiert werden.

VisIt

VisIt ist das Programm, mit dem aXqua seine vordefinierten dreidimensionalen Figuren wiedergibt (VisIt). aXqua wird mit VisIt 3.5.0 getestet.

Der Assistent lädt VisIt 3.5.0 für das verwendete Betriebssystem aus dem VisIt-Projekt (600 MB) herunter, überprüft den Download mit seiner veröffentlichten Prüfsumme und installiert ihn im ausgewählten Ordner. Dies erfordert keine Administratorrechte. Der Assistent gibt dann den VisIt launcher, die Datei bin/visit der Installation, in das Profil des Computers (Plugin-Profil) ein.

Für ein VisIt, das bereits installiert ist, wählen Sie den Installationsordner im Profileditor aus. aXqua betritt dann den Launcher. Dasselbe wird durch einen Eintrag in der Profildatei erreicht:

installations:
  visit: /home/user/opt/visit

axqua profile init Tritt automatisch in den Launcher ein, wenn der Befehl visit von Terminal aus gestartet werden kann oder wenn VisIt in /opt installiert ist.

Paraview

ParaView eignet sich für die interaktive Inspektion dreidimensionaler Ergebnisse.

Die Assistenten verwenden das ParaView-Paket des Betriebssystems, das eines der Systempakete ist, die auf der Registerkarte Check aufgeführt sind. Die Installation erfordert Administratorrechte (Simulationssoftware). Sobald das Paket installiert ist, gibt der Assistent das Programm /usr/bin/paraview in das Profil unter postprocessors.paraview ein. Stattdessen kann ein neueres ParaView von der ParaView-Website verwendet werden: Entpacken Sie es und wählen Sie den ungepackten Ordner als Installationsordner von ParaView im Profileditor aus.

ParaView öffnet einen OpenFOAM Fall direkt. Es liest weder das Ergebnisformat von TELEMAC (SELAFIN) noch VisIt. aXqua exportiert daher TELEMAC-Ergebnisse in ein Format, das beide Programme lesen (Paraview).

TELEMAC selbst wird mit dem Quellcode eines ParaView-Plugins verteilt, das SELAFIN-Dateien liest (optionals/addons/Paraview_Plugins/SerafinReader im TELEMAC-Ordner). Dieses Plugin muss für die verwendete Version von ParaView kompiliert werden und existiert nicht für VisIt. Der Export von aXqua erfordert weder.
