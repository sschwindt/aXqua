Warnmeldungen

Eine Warnung bedeutet, dass aXqua einen Schritt abgeschlossen hat, aber etwas gefunden hat, das das Ergebnis beeinflussen könnte. Warnungen erscheinen in den Protokolldateien mit der Ebene WARNING (Allgemeine Tipps & Logfiles). Diese Seite listet die häufigsten Warnungen mit ihrer Bedeutung und ihrem Heilmittel auf. Die Nachrichten werden zitiert, wie sie im Protokoll erscheinen, mit ... anstelle der Werte eines bestimmten Falls.

Bemerkung

Einzigartige Codes für alle Warnungen, die jede Nachricht mit ihrer Erklärung verknüpfen, sind in dieser Version noch nicht verfügbar.

Fall-Datei

deprecated config keys ..., still loaded but rename them

Die Fall-Datei verwendet Einträge einer älteren aXqua-Version. Das Fall wird korrekt gelesen. Führen Sie axqua migrate <case-file> --to-case aus, um eine Fall-Datei des aktuellen Typs daneben zu schreiben.

using the pre-rename artifact folder hydromate-case/

Der Fall wurde mit einer früheren Version erstellt, in der der Ausgabeordner einen anderen Namen hatte. aXqua verwendet weiterhin den vorhandenen Ordner. Benennen Sie den Ordner in axqua-case, wenn kein Job dieses Herbstes ausgeführt wird.

Preprocessing

BAMG meshing failed (...); retrying with a coarser background metric grid

Der Rechennetz-Generator war mit seinen ersten Einstellungen nicht erfolgreich und wiederholt das Verzahnen mit angepassten Einstellungen. Wenn kein Fehler folgt, ist das Rechennetz gültig und es ist keine Aktion erforderlich. Fällt die Verzahnung wiederholt aus, ist der Unterschied zwischen den Kantenlängen benachbarter Rechennetzzonen zu groß. Erhöhen Sie die kleinste Kantenlänge oder vergrößern Sie die Veredelungszone.

STABILITY RISK: inflow and outflow are resolved at different node spacings

Das Rechennetz ist an einem offenen Rand viel feiner als am anderen, was zu einer instabilen Simulation führen kann. Weisen Sie den Rechennetzzonen am Zufluss und am Ausfluss eine ähnliche Kantenlänge zu.

STABILITY RISK: liquid boundaries have ... inflow and ... outflow nodes

Auf einer Zufluss- oder Ausflusslinie wurden keine Rechennetzknoten gefunden. Stellen Sie sicher, dass die Zeilen auf dem Umriss des Untersuchungsgebiets liegen und dass ihr Typfeld inflow oder outflow enthält.

liquid_boundaries ... has no inflow/outflow type column; treating every line as inflow

Der Linienlayer hat kein Attributfeld, das Zufluss und Ausfluss identifiziert. Fügen Sie das Feld Type (inflow/outflow) (Offene Ränder) hinzu.

ground-truth data do not match; skipping HydroBayesCal setup

Das Modell wurde gebaut, aber die Messtabellen für die Kalibrierung wurden nicht geschrieben, weil die Feldmessungen nicht gelesen werden konnten oder nicht zu ihrem Punktlayer passen. Der Grund folgt in derselben Botschaft. Korrigieren Sie die Messdateien und wiederholen Sie Preprocessing, bevor Sie eine Kalibrierung starten.

finite volumes accept only TURBULENCE MODEL 1 (constant viscosity)

Die Finite-Volumen-Methode wurde zusammen mit einem anderen Turbulenzmodell ausgewählt. aXqua verwendet stattdessen das konstante Viskositätsmodell. Wählen Sie endliche Elemente, wenn ein Turbulenzmodell erforderlich ist (TELEMAC-Entscheidungen).

morphodynamics.enabled but neither bedload nor suspended_load is on

Die morphodynamische Simulation würde kein Sediment transportieren. Aktivieren Sie mindestens einen Transportmodus (Einrichtung von TELEMAC-GAIA).

Simulationen

fluxes did NOT reach the ... imbalance tolerance within the run

Zufluss und Ausfluss unterschieden sich am Ende des Laufs noch, so dass der Fluss nicht stetig ist. Erhöhen Sie hydrodynamics.duration und wiederholen Sie den Lauf. Wenn die Differenz nicht mehr abnimmt, überprüfen Sie den nachgelagerten Wasserstand und den Benetzungsbericht (TELEMAC Trockenläufe 2D/3D).

no hotstart end time; extend the run or relax abs_tolerance

Der Unterschied zwischen Zufluss und Ausfluss blieb nicht lange genug klein. Die Hotstart-Datei, die die Kalibrierung erfordert, wurde daher nicht geschrieben. Erhöhen Sie hydrodynamics.duration.

GRACJG: EXCEEDING MAXIMUM ITERATIONS (in der TELEMAC-Auflistung)

Ein lineares Solver von TELEMAC hat seine Genauigkeit nicht innerhalb der erlaubten Anzahl von Iterationen flussabschnittiert. Während des Befüllens eines trockenen Flussabschnitts ist diese Nachricht üblich und harmlos, sofern sie nach dem Befüllen des Flussabschnitts verschwindet. Wenn es bis zum Ende des Laufs anhält, sollte das Ergebnis nicht verwendet werden.

no 2D result at ...: the OpenFOAM case will use a flat lid and a cold start

Das OpenFOAM-Modell ist ohne ein TELEMAC-Warm-up aufgebaut, was die Rechenzeit erheblich erhöht. Führen Sie zuerst die stetige TELEMAC-Simulation aus (aXqua Warm-up Konzept).

checkMesh flagged marginal faces (the mesh is still runnable)

Der Rechennetz-Check von OpenFOAM fand eine kleine Anzahl von Zellen von geringer Qualität, typischerweise an Stufen im Gelände. Die Simulation kann durchgeführt werden. Wenn es instabil wird, erhöhen Sie die Zellgröße oder glätten Sie das Gelände an den gemeldeten Orten.

Kontrolle eines Falls

Die Überprüfung eines Falls (Check auf der Registerkarte Case Setup, Save in den Falleinstellungen oder axqua check <case-file>) meldet die folgenden Warnungen. Das Plugin zeigt jeden von ihnen als orangefarbenes Dreieck neben der betreffenden Einstellung.

the case names no simulation program, so nothing can be built or run

Die Fall-Datei enthält weder einen telemac noch einen openfoam-Block. Fügen Sie den Block des zu verwendenden Programms hinzu, zum Beispiel mit dem Schalter Simulate with TELEMAC auf der Seite TELEMAC der Fall-Einstellungen.

no discharge is set, so the steady simulation has no inflow

Der Fall kann gespeichert werden, aber der nächste Schritt des Workflows benötigt diese Einstellung. Geben Sie den Abfluss auf der Seite Liquid boundaries der Fall-Einstellungen ein (Offene Ränder).

The files of the validation situation 'High flow' show different discharges; the last one in the table was saved.

Eine Validierungssituation hat einen Abfluss, und die Tabelle Measurement files der Fall-Einstellungen zeigt sie in jeder Zeile der Situation an. Wo die Zeilen noch unterschiedliche Werte zeigen, wurde der letzte in der Tabelle gespeichert. Geben Sie den Abfluss der Situation in einer ihrer Zeilen ein; die anderen Zeilen folgen (Validierungssituation).

Hydrologieprüfung

Die Hydrologieprüfung eines Falls im Hydrologiemodus meldet die folgenden Warnungen (Hydrologie). Eine Warnung stoppt den Build nicht.

The rain peaks at ... mm/h

Mehr als 150 mm/h werden durch einen Wolkenbruch nur Minuten lang gehalten. Die übliche Ursache ist eine Reihe von Tiefen pro Intervall, die als Intensitäten gelesen werden: setzen Sie hydrology.rainfall_units auf mm.

The rain record has no value for ... intervals

Reihen der Regenreihe sind leer oder halten -999, so dass der DWD eine fehlende Messung markiert. aXqua hält ihre Intervalle und nimmt sie trocken, so dass kein Regen erfunden wird, sondern Regen, der in eine Lücke gefallen ist, in der Simulation fehlt. Füllen Sie die Lücken von einem benachbarten Pegel oder einem Radarprodukt oder stellen Sie sicher, dass das Ereignis außerhalb von ihnen liegt.

The rain comes from a reanalysis (ERA5)

Der Regen wurde von Open-Meteo heruntergeladen. Eine Reanalyse verbreitet einen Sturm über Zellen von 10 bis 30 km und einer Stunde und unterschätzt kurze Intensitäten. Verwenden Sie Pegel- oder Radardaten der nationalen Wetterbehörde, wo sie vorhanden sind, oder einen Designsturm.

The rain has no date, the weather does

Ein Designsturm oder ein Regentisch in Sekunden hat keine Kalenderzeit, während die Wetterserie Daten hat, beispielsweise von einem Ereignis, das der Datenassistent zuvor heruntergeladen hat. Das Wetter wird dann vom Beginn des Regens mit seinem Wind und der Verdunstung seiner eigenen Tage angewendet. Setzen Sie hydrology.rainfall_start auf das Datum und die Uhrzeit, zu der der Regen in der Wetterserie beginnen soll, oder entfernen Sie die Wetterserie, wenn sie zu einem anderen Ereignis gehört.

The weather series has no value for ... readings of ...

Zellen der Wetterserie sind leer oder halten -999, so dass der DWD eine fehlende Messung markiert. aXqua interpoliert jeden von ihnen in der Zeit zwischen den Messwerten davor und danach und die Windrichtung als Winkel, da sich Wind, Strahlung, Temperatur und Feuchtigkeit allmählich ändern und ein Wert von -999 sonst in den Wind und die Verdunstung eintreten würde, als ob er gemessen worden wäre. Über eine Lücke von wenigen Stunden verfehlt die Interpolation den Tagesverlauf: Längere Lücken von einer Nachbarstation aus füllen oder sicherstellen, dass das Ereignis außerhalb liegt.

The weather ends at ... s, the run at ... s

Nach dem Ende der Wetterserie gibt es keinen Wind und keine Verdunstung. Erweitern Sie die Serie bis zum Ende des Laufs.

The wind reaches ... m/s at 10 m

Über 40 m/s überprüfen Sie das Gerät: m/s, nicht km/h.

Evaporation reaches ... mm/h

Offenes Wasser verdampft selten mehr als 1,5 mm in einer Stunde. Überprüfen Sie die Einheit von et0 oder evaporation: mm / h, nicht mm / Tag.

Soil zone ... is ... with Ks = ... mm/h; Rawls et al. (1983) give ...

Die Leitfähigkeit einer Zone unterscheidet sich um mehr als den Faktor zehn vom Mittelwert ihrer Texturklasse. Das kann für einen gemessenen Boden richtig sein; oft ist es eine Einheit: Ks ist in mm / h und 1 cm / h ist 10 mm / h, 1e-6 m / s ist 3,6 mm / h.

No initial water content is given

Der Boden beginnt mit einer effektiven Sättigung von initial_saturation (0.3). Der Ablauf eines Sturms hängt stark vom Wassergehalt am Anfang ab: Geben Sie einen Messwert an, den ERA5-Landwert des Ereignisses (Daten Assistent) oder theta_i pro Zone.

The case has no outflow line: all rain stays in the catchment

Rechts für eine geschlossene Senke; andernfalls zeichnen Sie eine Ausflusslinie auf dem Umriss über den Auslass des Einzugsgebiets (Seite Liquid boundaries der Falleinstellungen).

A free outlet holds only where the flow leaves supercritical

Ein Free Outlet schreibt nichts vor. Bei einem langsameren Auslass füllt sich das Wasser in einen Teich, oder der Finite-Elemente-Kernel wird instabil, und der Finite-Volume-Kernel lässt Wasser dort ein, wo die Geschwindigkeit an der Ausflusslinie in den Bereich zeigt. Verwenden Sie normal_depth, es sei denn, die Steckdose ist steil und glatt, und overfall am unteren Rand eines Feldes, über das das Gelände fällt (Ränder und Outlet).

The finite-element kernel lets thin films drain slowly

TELEMAC validiert den Niederschlagsabfluss mit seinem endlichen Volumenkern und die hydrostatische Rekonstruktion von Chen und Noelle (hydrology.kernel: finite-volumes).

The run ends ... s after the rain

Wasser aus dem äußersten Ende des Einzugsgebietes nicht Flussabschnitt den Auslass vor dem Ende des Laufs, so dass die Rezession des Hydrographen abgeschnitten wird. Raise hydrology.drain_time.

The mesh will have about ... elements

Mehr als zwei Millionen Dreiecke brauchen lange, um zu berechnen. Heben Sie mesh.default_size oder die Kantenlängen der Rechennetzzonen an und verfeinern Sie, wo es darauf ankommt.

... % of the catchment drains across the outline where it is a wall

Der Umriss folgt nicht der dortigen Entwässerungstrennung: Das Gelände fällt unter einer Mauer aus dem Domäne ab, und das Wasser sammelte sich an Hangteichen. Machen Sie diese Dehnungen Ausflusslinien, oder verschieben Sie den Umriss auf die Teilung (Ränder und Outlet).

The terrain holds ... closed depressions

Eine Depression hält den Regen, bis er voll ist. Das ist richtig für einen Teich und falsch, wo das Gelände-Modell einen Durchgang oder die Öffnung einer Brücke blockiert: Schneiden Sie diese Öffnungen in das Gelände-Modell, zum Beispiel als Struktur (Geodaten).

The terrain model could not be analyzed

Die Gelände-Analyse des Checkups ist fehlgeschlagen, in der Regel, weil das Gelände-Modell den Umriss nicht abdeckt. Der Build selbst benennt das Problem genauer.

Profil dieses Computers

Die Überprüfung des Profils (Check auf der Registerkarte Configuration oder axqua profile check) meldet die folgenden Warnungen. Das Plugin zeigt jeden von ihnen als orangefarbenes Dreieck neben dem betreffenden Eintrag. Ein Klick auf das Dreieck öffnet die Nachricht. Eine Warnung verhindert nicht das Speichern des Profils.

no environment script is set for ..., so simulations with it cannot be started

Im Profil ist nicht angegeben, wo TELEMAC oder OpenFOAM installiert ist. Wählen Sie den Installationsordner oder das Umgebungsskript der Installation im Profileditor (Definieren Sie Solver Bindungen). Lassen Sie beide Einträge leer, wenn das Programm nicht auf diesem Computer verwendet wird.

the installation folder of ... holds several environment scripts oder no environment script of ... was found in the installation folder

Das Profil benennt den Installationsordner eines Simulationscodes und kein Umgebungsskript, und aXqua kann das Skript nicht aus dem Ordner bestimmen. Eine TELEMAC-Installation kann ein Umgebungsskript pro Compiler-Konfiguration enthalten. Wählen Sie das Umgebungsskript selbst im Profileditor aus.

the installation folder of ... does not exist

Das Profil benennt einen Ordner, der sich nicht auf diesem Computer befindet, beispielsweise weil das Programm verschoben oder entfernt wurde. Wählen Sie den Ordner im Profileditor erneut aus oder löschen Sie den Eintrag. Ein Programm, dessen Umgebungsskript oder Programmdatei in das Profil eingegeben wird, funktioniert weiterhin.

the environment script of ... is not in the Installation folder entered for it oder the program of ... is not in the installation folder entered for it

Die beiden Einträge eines Programms weisen auf unterschiedliche Anlagen hin. aXqua verwendet das Umgebungsskript oder die Programmdatei, und der Ordner hat keine Wirkung. Wählen Sie den Ordner aus, zu dem die Datei gehört, oder löschen Sie den Ordner.

this version of aXqua does not know the entry ...; it is kept as it is and not used

Das Profil enthält einen Eintrag, den die installierte Version von aXqua nicht kennt. Wenn eine neuere Version von aXqua oder des Plugins den Eintrag geschrieben hat, aktualisieren Sie aXqua und der Eintrag wird wirksam. Wenn es sich bei dem Eintrag um einen tippfehler in einem von Hand bearbeiteten Profil handelt, benennt die Nachricht den Eintrag, der wahrscheinlich gemeint ist. Korrigieren Sie den Namen in der Profildatei. Die restlichen Einträge des Profils werden in jedem Fall verwendet, und das Speichern des Profils behält den Eintrag.

the variables of ... were already set before its environment script ran

Die Terminal oder QGIS-Sitzung enthielt bereits die Einstellungen des Simulationsprogramms, bevor aXqua das Umgebungsskript geladen hat, typischerweise weil eine systemweite Startdatei sie lädt. Ein Job erbt diese Einstellungen nicht. Stellen Sie sicher, dass das Umgebungsskript des Profils allein die Installation einrichtet, insbesondere wenn mehrere Versionen des Programms installiert sind.

... processes are requested for ..., but this computer has ... logical cores

Mehr Prozesse als Prozessorkerne verlangsamen eine Simulation. Reduzieren Sie die Anzahl der Prozessorkerne im Profil.

this is OpenFOAM ...; aXqua writes input files for v2406

Das Umgebungsskript gehört zu einer anderen OpenFOAM-Version. aXqua schreibt seine Eingabedateien für die Version v2406, und andere Versionen können sie ablehnen. Geben Sie das Umgebungsskript von OpenFOAM v2406 im Profil ein.

Installation der Simulationssoftware

Die Registerkarte Check eines Installationsassistenten, die Registerkarte Installation einer fertigen Installation und axqua install plan melden die folgenden Warnungen. Eine Installation kann mit einer Warnung gestartet werden.

... of ... system packages are not installed

Die Installation erfordert Pakete des Betriebssystems, die fehlen. Die Nachricht listet sie auf und gibt den Befehl, der sie installiert, was Administratorrechte erfordert. Klicken Sie im Assistenten auf Install the packages… oder kopieren Sie den Befehl in ein Terminal und klicken Sie auf Check again (Simulationssoftware). Für OpenFOAM mit einer vorhandenen OpenFOAM v2406 werden die meisten der aufgeführten Pakete nur zum Kompilieren von OpenFOAM selbst benötigt, und die Installation funktioniert normalerweise ohne sie.

the package sources of this system do not offer: ...

Das Betriebssystem kennt kein Paket, das der Installer benennt, in der Regel, weil das System älter oder neuer ist als das, für das der Installer geschrieben wurde. Die Installation funktioniert möglicherweise weiterhin, wenn ein anderes Paket die gleichen Dateien bereitstellt. Andernfalls muss ein Administrator eine Paketquelle hinzufügen.

the list of system packages could not be read from the installer

aXqua liest die Liste der erforderlichen Pakete aus dem Installationsskript und hat sie in dieser Version des Skripts nicht gefunden. Die Installation kann gestartet werden. Es endet mit einer eigenen Nachricht, wenn ein Paket fehlt.

... GiB are free in ...; the installation needs about ... GiB

Der Antrieb des Installationsordners kann zu klein sein. Wählen Sie einen Ordner auf einem Laufwerk mit mehr freiem Speicherplatz auf der Settings Registerkarte des Assistenten.

... is inside your home folder, which other users usually cannot open

Eine Installation für alle Benutzer wurde mit einem Ordner in Ihrem Home-Ordner versehen. Andere Benutzerkonten haben normalerweise keinen Zugriff auf einen Home-Ordner, so dass sie die Programme nicht ausführen können. Wählen Sie einen Ordner außerhalb, wie /opt/openfoam-sediment-v2406.

... exists already oder ... holds an installation of this installer, which is continued

Der Installationsordner enthält eine frühere Installation. Der Installer fährt damit fort: Er behält, was heruntergeladen wird, und baut das Programm erneut auf. Wählen Sie einen anderen Ordner aus, um die frühere Installation unberührt zu lassen.

no OpenFOAM v2406 was found on this computer, so it is compiled from its source code

Die Zusammenstellung von OpenFOAM dauert mehrere Stunden und etwa 20 GB. Wenn OpenFOAM v2406 installiert ist, wählen Sie die Datei etc/bashrc auf der Registerkarte Settings des Assistenten aus. Ein verpacktes OpenFOAM v2406, das ein Administrator in wenigen Minuten installiert, vermeidet die Zusammenstellung (OpenFOAM).

ParaView is not installed

Die Assistenten verwenden das ParaView-Paket des Betriebssystems und es ist nicht installiert. VisIt ist trotzdem installiert. Installieren Sie die auf der Registerkarte Check aufgeführten Systempakete oder geben Sie eine andere ParaView im Profileditor (Paraview) ein.

VisIt was not installed, so it was not entered in the profile

OpenFOAM und der Sediment Solver werden installiert und in das Profil eingegeben, aber der Installateur hat VisIt nicht dort verlassen, wo aXqua es erwartet. Die Simulationssoftware funktioniert ohne VisIt. Installieren Sie VisIt allein mit dem Assistenten für ParaView und VisIt auf der Registerkarte Configuration oder mit axqua install start postprocessors (VisIt).

'Download the input files of the example cases' did not complete

TELEMAC ist installiert und funktioniert, aber die Eingabedateien seines Beispiels Fälle wurden nicht vollständig heruntergeladen. Die Nachricht zitiert die letzten Zeilen des Installationsprotokolls. Die übliche Ursache ist der Download-Server von TELEMAC, der weitere Anfragen nach vielen Downloads aus einem Netzwerk (Rate limit exceeded, error: 429) für eine Weile ablehnt. Wiederholen Sie den Download später mit dem Befehl, dass die Nachrichtennamen axqua install telemac-examples <folder>. Es holt nur die Dateien, die noch fehlen.

the installation could not be entered in the profile

Das Programm ist installiert, aber das Profil des Computers konnte nicht geschrieben werden, in der Regel, weil das vorhandene Profil einen Fehler enthält, oder weil eine andere Installation das Profil im gleichen Moment schrieb und nicht beendet wurde. Die Nachricht listet die Einträge auf. Öffnen Sie den Profileditor auf der Registerkarte Configuration, korrigieren Sie das Profil und geben Sie sie dort ein (Plugin-Profil).

Simulationssoftware

NOTE: already present in the ambient environment

Die Variablen eines Simulationscodes wurden bereits im Terminal gesetzt, bevor aXqua das Umgebungsskript gelesen hat. Ein Job erbt nicht die Einstellungen eines Terminal. Stellen Sie sicher, dass die Bindung Solver das korrekte Umgebungsskript (Definieren Sie Solver Bindungen) benennt. Andernfalls kann eine Simulation im Terminal funktionieren und als Job fehlschlagen.
