Fehlermeldungen

Ein Fehler bedeutet, dass aXqua keinen Schritt abschließen konnte. Fehler erscheinen in den Protokolldateien mit der Ebene ERROR und in der Nachrichtenleiste des Plugins (Allgemeine Tipps & Logfiles).

Jeder Fehler gehört zu einer von fünf Kategorien. Die Kategorie bestimmt, wo nach der Ursache gesucht werden soll:

Kategorie

Code

Wohin schauen

Fall-Datei

axqua.config

Ein Eintrag der Fall-Datei fehlt, ist falsch geschrieben oder hat einen ungültigen Wert.

Geodaten

axqua.geodata

Eine Eingabe Layer oder Raster fehlt oder fehlt eine erforderliche Eigenschaft.

Simulationssoftware

axqua.environment

TELEMAC oder OpenFOAM sind mit den aktuellen Bindungen Solver nicht erreichbar.

Simulation

axqua.solver

Der Simulationscode begann und stoppte mit einem Fehler. Lesen Sie den eigenen Output.

Rechennetz

axqua.mesh

Das Rechennetz konnte nicht erstellt werden oder ist nicht nutzbar.

Wo aXqua ein Heilmittel kennt, enthält die Fehlermeldung es. Bei einem fehlgeschlagenen Job wird der Fehler mit seinem Code und seiner Abhilfe in der Datei status.json des Jobs gespeichert und unter der Jobliste des Plugins angezeigt.

Bemerkung

Einzigartige Codes für die einzelnen Fehler innerhalb dieser Kategorien, die jede Nachricht mit ihrer Erklärung verknüpfen, sind in dieser Version noch nicht verfügbar.

Installation

ModuleNotFoundError: No module named 'axqua'

Das aXqua-Programm ist nicht in der aktiven Python-Umgebung installiert. Aktivieren Sie die Umgebung und installieren Sie aXqua (QGIS Plugin). Eine Kopie des Repositorys allein reicht nicht aus, da der Quellcode im Unterordner src/ liegt.

ImportError: libjxl.so...: cannot open shared object file

Eine Systembibliothek, die die Geodatenpakete benötigen, stimmt nicht mit ihrer Version überein. Dies geschieht, wenn Pakete unterschiedlichen Ursprungs in einer Umgebung gemischt werden. Erstellen Sie die Umgebung erneut aus environment.yml, die alle Geodatenpakete konsistent aus einer Quelle installiert.

axqua could not be found (Plugin)

Das Plugin hat das Programm axqua nicht gefunden. Die Nachricht listet die drei Orte auf, die gesucht wurden. Geben Sie den vollständigen Pfad des Programms unter aXqua > Settings ein und klicken Sie auf Test (QGIS Plugin).

Installation der Simulationssoftware

Die Registerkarte Check eines Installationsassistenten, die Registerkarte Installation einer fehlgeschlagenen Installation und axqua install melden die folgenden Fehler. Eine Installation kann nicht mit einem Fehler des Check gestartet werden.

there is no installer for this system

Die Installationsskripte existieren für Debian 12, Ubuntu 22.04, Ubuntu 24.04 und Linux Mint 22, und das TELEMAC-Installationsprogramm deckt Ubuntu 22.04 nicht ab. Das OpenFOAM-Installationsprogramm und das VisIt-Installationsprogramm benötigen zusätzlich einen x86-64-Prozessor. Auf einem System, das auf einem der unterstützten Systeme aufgebaut ist, wählen Sie das Basissystem unter Further settings auf der Registerkarte Settings des Assistent. Andernfalls installieren Sie das Programm von Hand und geben Sie es in den Profil-Editor (Simulationssoftware).

TELEMAC and OpenFOAM are installed in the Windows Subsystem for Linux

Die Simulationsprogramme laufen nicht in Windows selbst. Installieren Sie eine Linux-Distribution im Windows-Subsystem für Linux und starten Sie dort die Installation (Simulationssoftware).

the installers refuse to run as the user root

Starten Sie QGIS oder Terminal als gewöhnlicher Benutzer. Administratorrechte werden nur für die Systempakete benötigt.

... is a folder of Windows

Im Windows-Subsystem für Linux gehört ein Ordner unter /mnt/ zu Windows. Wählen Sie einen Ordner im Linux-Dateisystem aus, beispielsweise im Home-Ordner.

the folder ... has a space in its name

Weder TELEMAC noch OpenFOAM können in einen Ordner eingebaut werden, dessen Pfad einen Space enthält. Wählen Sie einen anderen Ordner aus.

... cannot be the folder of an installation for all users

Am Ende einer Installation für alle Benutzer wird der gesamte Installationsordner an den Administrator übergeben. Ein Ordner wie /opt oder /usr selbst oder Ihr Home-Ordner wird mit allem anderen, was er enthält, übergeben. Wählen Sie einen eigenen Ordner aus, z. B. /opt/telemac.

... exists and you cannot write into it

Der Installationsordner einer Installation für alle Benutzer gehört jemand anderem und wurde nicht durch eine Installation von aXqua für alle Benutzer erstellt, so dass aXqua sie nicht übernimmt. Wählen Sie einen Ordner aus, der noch nicht existiert.

... needs the rights of an administrator

Eine Installation für alle Benutzer benötigt das Passwort eines Administrators vor und nach dem Build, und diese Sitzung konnte weder den Passwortdialog des Desktops öffnen noch in einem Terminal fragen. Dies geschieht bei einer Installation, die ohne Desktop losgelöst gestartet wurde. Starten Sie es in einem Terminal mit axqua install start <program> --for-all-users --foreground oder lassen Sie einen Administrator den Befehl ausführen, dass die Nachrichtennamen benannt werden, und starten Sie die Installation erneut. Zu diesem Zeitpunkt wurde nichts gebaut.

... exists and was not made by this installer

Der OpenFOAM-Installer installiert in einen neuen Ordner oder setzt eine eigene Installation fort. Wählen Sie einen Ordner aus, der noch nicht existiert.

... holds an installation made by another version of the installer or against another OpenFOAM

Das OpenFOAM-Installationsprogramm setzt nur das fort, was dieselbe Version mit demselben OpenFOAM gestartet hat. Öffnen Sie den Assistenten mit Install OpenFOAM…, beantworten Sie Yes auf die Frage, ob Sie erneut installieren möchten, und wählen Sie Remove the existing installation and install it again in its folder oder einen neuen Ordner aus.

there is no earlier installation to remove: ...

Remove the existing installation wurde für einen Ordner ausgewählt, der keine Installation enthält, die ein Installer von aXqua erstellt hat. aXqua entfernt nur solche Anlagen. Wählen Sie den Ordner der vorhandenen Installation aus oder installieren Sie ihn in einem neuen Ordner.

the SALOME archive ... does not exist oder the OpenFOAM environment script ... does not exist

Eine Datei, die auf der Registerkarte Settings des Assistenten ausgewählt wurde, befindet sich nicht auf diesem Computer. Wählen Sie es erneut aus oder löschen Sie das Feld.

... belongs to OpenFOAM release ...

Der Sedimenttransport Solver ist für OpenFOAM v2406 gebaut und die ausgewählte Installation ist eine andere Version. Wählen Sie die Datei etc/bashrc von OpenFOAM v2406 oder lassen Sie den Assistenten OpenFOAM kompilieren.

the installer scripts could not be downloaded

aXqua lädt die TELEMAC-Installationsskripte herunter, bevor es den Computer überprüft und das Repository nicht flussabschnitt. Der OpenFOAM-Installer und der Quellcode von Olsens Solver werden mit aXqua ausgeliefert und nicht heruntergeladen. Überprüfen Sie die Internetverbindung. Für einen Computer ohne Verbindung kopieren Sie Installateur-Repository und wählen Sie den Ordner unter Further settings aus (in einer Terminal: die Umgebungsvariable AXQUA_INSTALLERS).

the OpenFOAM installer does not run with any Python on this computer

Der OpenFOAM-Installer erfordert einen neueren Python als der, der aXqua ausführt, und aXqua fand keinen neueren. Installieren Sie Python 3.12 oder neuer, zum Beispiel mit Miniforge, und installieren Sie aXqua damit.

'...' ended with an error

Ein Schritt der Installation ist fehlgeschlagen. Die Nachricht zitiert die letzten Zeilen des Installationsprotokolls, die normalerweise die Ursache benennen, und gibt den Standort des vollständigen Protokolls an. Typische Ursachen sind ein fehlendes Systempaket, ein unterbrochener Download und ein volles Laufwerk. Beheben Sie die Ursache und starten Sie die Installation erneut mit dem gleichen Ordner: Der Installer fährt mit dem fort, was bereits heruntergeladen und gebaut wurde.

Die Zeilen remote: Retry later und error: 429 bedeuten, dass der Download-Server von TELEMAC vorübergehend weitere Anfragen ablehnt, was nach vielen Downloads aus einem Netzwerk in kurzer Zeit auftritt. Warten Sie einige Minuten und starten Sie die Installation erneut.

the installer finished, but did not produce ...

Der Installateur meldete Erfolg, aber ein Programm, das er hätte bauen sollen, fehlt, so dass der Build teilweise fehlgeschlagen ist. Durchsuchen Sie das Installationsprotokoll nach der ersten Zeile, die Error enthält.

the program this installation enters in the profile is not on this computer

Die Installation besteht aus einem Paket des Betriebssystems und das Paket ist nicht installiert. Installieren Sie die Systempakete, die auf der Registerkarte Check des Assistenten aufgeführt sind, und starten Sie die Installation erneut.

without VisIt, this installation is the system package of ParaView alone, which is not installed yet

Mit der Auswahl ParaView only lädt die Installation der Postprozessoren nichts herunter: ParaView ist ein Paket des Betriebssystems, und der Assistent gibt es nur im Profil ein. Installieren Sie die Systempakete, die auf der Registerkarte Check aufgelistet sind, was Administratorrechte erfordert, und klicken Sie auf Check again (Paraview).

the installation ended without a result

Der Installationsprozess verschwand, in der Regel, weil der Computer neu gestartet oder der Benutzer abgemeldet wurde. Starten Sie die Installation erneut mit dem gleichen Ordner.

Kontrolle eines Falls

Die Überprüfung eines Falls (Check auf der Registerkarte Case Setup, Save in den Fall-Einstellungen oder axqua check <case-file>) meldet die folgenden Fehler. Das Plugin zeigt jeden von ihnen als dunkelrotes Dreieck neben der betreffenden Einstellung. Ein Fehler verhindert nicht das Speichern des Falls, aber das Modell kann nicht gebaut werden, bis es korrigiert ist.

... is required oder ... is not set

Eine Einstellung, die jeder Fall braucht, ist leer, zum Beispiel das Gelände-Modell, die Modellgrenze oder die Zufluss- und Ausflusslinien. Wählen Sie die Datei in den Herbst-Einstellungen (Open case settings… auf der Registerkarte Case Setup).

the file of ... does not exist

Die Fall-Datei benennt eine Datei, die sich nicht am angegebenen Speicherort befindet. Ein Pfad, der nicht an der Wurzel des Laufwerks beginnt, wird relativ zum Ordner der Fall-Datei gelesen. Wählen Sie die Datei erneut in den Herbst-Einstellungen aus.

... is not a setting of a case oder ... is not a block of a case file

Die Fall-Datei enthält einen Namen, den aXqua in den meisten Fällen aufgrund eines Tippfehlers nicht kennt. Die Botschaft schlägt den Namen vor, der wahrscheinlich gemeint war. Korrigieren Sie den Namen in der Fall-Datei mit einem Texteditor.

the case file is not valid YAML

Die Struktur der Datei wird beschädigt, beispielsweise durch einen fehlenden Doppelpunkt oder eine falsche Einbuchtung. Die Nachricht benennt die Zeile. Korrigieren Sie es mit einem Texteditor. Die Fall-Einstellungen behalten das Original einer Fall-Datei als <name>.bak beim ersten Speichern.

the file does not contain the blocks of a case

Die Datei ist gültig YAML, aber keine Fall-Datei, zum Beispiel eine Liste. Wählen Sie die richtige Datei aus.

the case file cannot be read

Die Datei existiert nicht oder kann nicht gelesen werden. Überprüfen Sie den Pfad und die Zugriffsrechte.

Profil dieses Computers

Die Überprüfung des Profils (Check auf der Registerkarte Configuration oder axqua profile check) meldet die folgenden Fehler. Das Plugin zeigt jeden von ihnen als dunkelrotes Dreieck neben dem betreffenden Eintrag. Ein Fehler verhindert nicht das Speichern des Profils, aber die Funktion, die vom Eintrag abhängt, funktioniert nicht, bis der Eintrag korrigiert ist.

the ... does not exist, the ... launcher ... is not executable oder the ... program was not found in the installation folder ...

Das Profil benennt eine Programmdatei, die sich nicht auf diesem Computer befindet oder die möglicherweise nicht gestartet wird, oder einen Installationsordner, der das Programm nicht enthält. Wählen Sie die Datei erneut im Profileditor aus.

the environment script of ... does not exist

Das Profil benennt ein Umgebungsskript, das sich nicht auf diesem Computer befindet. Wählen Sie das Skript der Installation (Definieren Sie Solver Bindungen).

... cannot be reached

aXqua hat das Umgebungsskript geladen und konnte das Simulationsprogramm nicht starten. Die Botschaft sagt, was fehlt. Stellen Sie in einem Terminal sicher, dass die Installation von selbst funktioniert und dass das Profil das Umgebungsskript dieser Installation benennt.

the job root ... cannot be written to

aXqua kann keine Dateien im Ordner für Jobs erstellen. Wählen Sie einen Ordner auf einem Laufwerk mit Schreibzugriff und ausreichend freiem Speicherplatz.

the launcher must be one of ..., the number of processes must be at least 1 und ähnliche

Ein Eintrag des Profils hat einen Wert, der nicht möglich ist. Die Nachricht benennt den Eintrag und die zulässigen Werte.

Fall-Datei

... unknown config keys [...]

Ein Block der Fall-Datei enthält einen Eintrag, den aXqua normalerweise aufgrund eines Tippfehlers nicht kennt. Die Nachricht benennt den Block und den Eintrag. Vergleichen Sie die Schreibweise mit der Vorlage in cases/case-template/.

telemac.pysource is not set oder TELEMAC pysource script not found

aXqua weiß nicht, wo TELEMAC installiert ist, oder das angegebene Umgebungsskript existiert nicht. Erstellen Sie das Profil des Computers mit axqua profile init oder korrigieren Sie seine Bindung für TELEMAC (Definieren Sie Solver Bindungen).

outflow_condition: elevation requires boundaries.prescribed_elevation

Der Ausflussrand ist auf eine konstante Wasserspiegellage eingestellt, jedoch ist keine Höhe angegeben. Geben Sie boundaries.prescribed_elevation ein oder wählen Sie eine andere Ausflussbedingung (Offene Ränder).

initialization.prewet_depth needs geodata.mesh_zones

Der vorbenetzte Start füllt die Gerinne-Zonen mit Wasser und erfordert daher eine Rechennetz-Zone Layer mit einer Zone, deren Name channel (Ausgangsbedingungen) enthält.

morphodynamics.enabled but no geodata.dem_target / dem_of_difference provided

Ein morphodynamischer Fall erfordert die gemessene Bettänderung als Referenz. Geben Sie ein zweites Gelände-Modell oder ein DGM der Differenz ein (Morphodynamische Simulation).

Preprocessing und Simulationen

BAMG failed oder Fatal error in the meshgenerator

Der Rechennetz-Generator konnte das Rechennetz auch nach Wiederholung des Versuchs mit angepassten Einstellungen nicht erstellen. Die Kantenlängen benachbarter Rechennetzzonen unterscheiden sich zu stark. Erhöhen Sie die kleinste Kantenlänge oder vergrößern Sie die Veredelungszone, so dass sich die Dreiecksgröße allmählich ändern kann.

TELEMAC stoppt beim ersten Zeitschritt mit einer Nachricht des Unterprogramms DEBIMP

Das Zufluss Querprofil ist trocken, so dass TELEMAC den Abfluss nicht darüber verteilen kann. Stellen Sie sicher, dass die Zuflusslinie in der Gerinne liegt und dass die Wassertiefe der gefüllten Strecke am Zufluss (initialization.dry_start_depth) das Bett entlang der gesamten Linie bedeckt.

TELEMAC-2D stopped the run ... because a value left its limits

Die Wassertiefe oder eine Geschwindigkeitskomponente hat den Bereich verlassen, den das Keyword LIMIT VALUES der Steuerdatei zulässt, was 1000 m / s für die Geschwindigkeit ist. Ein solcher Wert ist eine numerische Instabilität und kein Fluss. TELEMAC-2D selbst beendet einen solchen Lauf ohne Fehlercode, so dass aXqua den Stopp aus dem Eintrag liest und den Job als FAILED markiert. Die Nachricht gibt die Menge, ihren Wert, die Koordinaten der Rechennetzknoten und die simulierte Zeit an. Inspizieren Sie das Rechennetz, die Sohlhöhe und die erste Wassertiefe an diesen Koordinaten in QGIS. Häufige Ursachen sind eine Spüle oder ein offener Rand auf Zellen, die fast trocken sind, ein anfänglicher Wasserspiegel, der weit von dem stetigen entfernt ist, und ein zu großer Zeitschritt (hydrodynamics.desired_courant). Interne Vermittlungsleitungen, die als Quellgebiete mit einer festen Rate (boundaries.internal_sources: true) angelegt werden, können diesen Stopp beim ersten Zeitschritt bewirken, da der Abfluss dann unabhängig von der Wassertiefe von einem schmalen Streifen abgezogen wird. Verwenden Sie stattdessen den Block gain_lose, der die Auszahlung durch die Wassertiefe einschränkt (TELEMAC-Entscheidungen).

RIGID LID DOES NOT APPLY HERE

Der Wasserspiegel des TELEMAC-Ergebnisses fällt in Schritten, die den lokalen Wassertiefe überschreiten, zum Beispiel an den Slots eines Fischpasses. Ein fester Deckel kann solch ein Wasserspiegel nicht darstellen. Verwenden Sie openfoam.mode: vof für dieses Fall (OpenFOAM-Auswahl).

Arbeitsplätze

Ein Job scheitert unmittelbar nach dem Start

In den meisten Fällen ist die Simulationssoftware vom Job aus nicht erreichbar. Lesen Sie runner.log des Jobs und überprüfen Sie das Profil mit axqua profile check (Definieren Sie Solver Bindungen). Beachten Sie die Warnung vor der Umgebung (Warnmeldungen): Ein Job erbt nicht die Einstellungen von Terminal oder von QGIS.

the 'systemd' launcher is not available on this machine

Die Linux-Benutzerdienste, die aXqua standardmäßig verwendet, sind nicht verfügbar, was für einige Remote-Sitzungen typisch ist. Senden Sie den Job mit der Option --launcher posix oder wählen Sie posix unter How jobs are detached im Profil-Editor des Plugins (Configuration Registerkarte).

Ein Job bleibt im Zustand RUNNING, obwohl nichts berechnet wird

Abfragen Sie den Zustand mit axqua status <job-id> oder klicken Sie auf Refresh unterhalb der Jobliste. aXqua überprüft dann, ob der Prozess noch existiert und kennzeichnet den Job als FAILED, wenn dies nicht der Fall ist, beispielsweise nach einem Neustart des Computers. Der Job kann erneut eingereicht werden.

Plugin

aXqua fehlt in der Liste der installierten Plugins

QGIS listet ein Plugin nur dann auf, wenn es die Datei metadata.txt im Plugin-Ordner lesen kann und ein Plugin mit einer unlesbaren Datei ohne Nachricht überspringt. Führen Sie python scripts/build_plugin_zip.py --check im Repository aus, das die Datei auf die gleiche Weise wie QGIS liest und die Zeile meldet, die nicht gelesen werden kann.

Die Registerkarten des Workflows zeigen nur die Notiz, um einen Fall hinzuzufügen

Es wird kein Fall ausgewählt oder die Fall-Datei konnte nicht gelesen werden. Fügen Sie einen Fall auf dem Case Setup hinzu. Wenn die Registerkarten leer bleiben, führen Sie axqua case-status <case-file> --no-write in einem Terminal aus, um die Fehlermeldung zu erhalten.

Ein Ergebnis Layer wird ohne Farben geladen

Der Name einer Ergebnisvariablen unterscheidet sich von der erwarteten. Die Datei ist intakt. Weisen Sie den Stil in den QGIS Layer Eigenschaften zu.
