description=Set up, run and monitor TELEMAC and OpenFOAM models of free-surface water bodies (rivers, lakes, reservoirs, hydraulic structures) from QGIS, with jobs that keep running after QGIS is closed.
about=aXqua turns geodata into a calibration-ready hydro- and morphodynamic model (TELEMAC-2D/3D with GAIA, or an OpenFOAM interFoam free-surface case) and drives it through a persistent job runner. Simulations are launched as detached system jobs, so they survive closing QGIS, and are rediscovered with their live state when you reopen it. Results load back as mesh, raster and vector layers, with depth and velocity styling applied to the meshes. The plugin drives the aXqua command-line tool, installed separately with 'pip install axqua', and needs a working TELEMAC and/or OpenFOAM installation.

changelog=1.0.2
    - The inflow of a model received no discharge when the south-westernmost node
      of its outline was the last node of a liquid boundary line: TELEMAC then
      numbers that line last, and the discharge went to the outflow. The numbering
      of aXqua now follows TELEMAC in this case too. Rebuild a model that was built
      with an earlier version.
    - The gauge tool (scripts/gauge_data.py) keeps the fetched gauge when a table
      is downloaded, so the hydrograph and the rating curve can be saved one after
      the other.
    1.0.1
    - The aXqua program is published on PyPI. Install it with 'pip install axqua'
      and upgrade it with 'pip install --upgrade axqua'; Git and a copy of the
      repository are no longer needed.
    1.0.0
    - The first stable release. It needs the aXqua program 1.0 or newer.
    - Documentation in English, German and French at https://axqua.eu. Help opens
      a copy built on this computer when there is one, else the published pages,
      in the language of QGIS.
    - Clean Up, left of Help, removes what a case no longer needs: working folders
      of interrupted runs, listings, earlier time steps of results, processor
      folders of reconstructed OpenFOAM runs and exports. Inputs, the case file,
      the built model and the last time step of a result are never offered, and
      nothing is removed while a run may still use it.
    - One Simulations tab with Baseline (Telemac), OpenFOAM, Mesh convergence and
      Morphodynamics, and a mesh convergence study for OpenFOAM.
    - Case settings replace the project file: the cases are kept in the QGIS
      settings, required entries are marked, and a table lists the measurements
      for calibration and validation.
    - The outlet of an OpenFOAM model can follow a stage-discharge relation (the
      boundary condition of BAW).
    - OpenFOAM runs on any number of processes; the results of an earlier run are
      set aside in previous-run instead of being deleted.
    - Calibration against the targets of the case file, water depth and velocity.
    - The installation wizards are tabs, run the fixes they ask for, and install
      again on request.
    0.5.0
    - Installation wizards for TELEMAC, OpenFOAM with the sediment solvers, ParaView
      and VisIt, for you alone or for all users of the computer.
    - The OpenFOAM installation no longer depends on the website of the sediment
      solvers: their source code ships with aXqua.
    - A profile per computer names where the programs are installed; a case file
      (.axq-case) describes the reach. The profile editor and the case editor edit
      them, and a check reports everything that is not in order at once.
    - The panel follows the workflow: Configuration, Case Setup, Preprocessing,
      Hydraulic simulation, Morphodynamic simulation, Calibration and validation,
      Postprocessing, Batch-processing, each with its Help page.
    - Jobs of a case run one after the other and keep running when QGIS is closed.
    - Validation of a calibrated model against measurements of another flow
      situation.
    - Fine sediment over a bed that stays in place, simulated with OpenFOAM.
    - Results export to ParaView and VisIt; a loaded result shows its last time
      step.
    - The Isar example case downloads with its data and a step-by-step guide.
    - Export movie is in the aXqua menu, and QGIS stays responsive while aXqua
      works.
    - Errors show what aXqua said and what to do about it.
    0.2.0
    - First release.
    - Persistent job runner: submit, monitor and cancel TELEMAC/OpenFOAM runs that
      outlive the QGIS session.
    - Job dashboard with adaptive polling, rediscovery from a .axqua-prj project.
    - Tabs generated from axqua's capability matrix, so a case only offers what it
      can actually do.
    - Result loading with depth and velocity styling, plus an A3 print layout.
    - Processing algorithms that submit and return rather than blocking QGIS.
