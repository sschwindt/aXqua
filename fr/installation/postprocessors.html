Après traitement

QGIS affiche directement les résultats en moyenne de profondeur et n’a pas besoin de logiciels supplémentaires. Les résultats tridimensionnels sont mieux vus avec un programme de visualisation dédié. aXqua fonctionne avec deux d’entre eux, et les deux sont facultatifs.

Les deux programmes sont installés par un assistant. Sur un ordinateur qui exécute OpenFOAM, l’assistant OpenFOAM les installe avec les solveurs (Ouvrir). Sur un ordinateur qui fonctionne uniquement TELEMAC, cliquez sur Install ParaView and VisIt… dans la boîte Simulation & postprocessing software de l’onglet Configuration. L’assistant a deux paramètres, l’installation dossier de VisIt et la sélection des programmes, et fonctionne comme décrit pour le logiciel de simulation (Logiciel de simulation). Il est disponible sur Debian 12, Ubuntu 22.04, Ubuntu 24.04 et Linux Mint 22. La même installation est lancée à terminal avec axqua install start postprocessors.

Sélection des programmes. ParaView and VisIt est la valeur par défaut. ParaView only quitte VisIt : rien n’est téléchargé, et l’assistant entre dans le ParaView du système d’exploitation dans le profil. L’assistant OpenFOAM offre la même sélection et, en outre, None. Dans un terminal, l’option --no-visit quitte VisIt. aXqua recommande d’installer VisIt, car il rend ses figures tridimensionnelles prédéfinies avec VisIt (VisIt). Sans VisIt, ces chiffres ne sont pas disponibles, et les résultats tridimensionnels sont inspectés de manière interactive dans ParaView. VisIt peut être installé à tout moment après avec le même assistant.

VisIt

VisIt est le programme avec lequel aXqua rend ses figures tridimensionnelles prédéfinies (VisIt). aXqua est testé avec VisIt 3.5.0.

L’assistant télécharge VisIt 3.5.0 pour le système d’exploitation utilisé depuis le projet VisIt (600 MB), vérifie le téléchargement en fonction de son bilan publié et l’installe dans le dossier sélectionné. Cela ne nécessite aucun droit d’administrateur. L’assistant entre ensuite le VisIt launcher, qui est le fichier bin/visit de l’installation, dans le profil de l’ordinateur (Profil d’extension).

Pour un VisIt déjà installé, sélectionnez son installation dossier dans l’éditeur de profil. aXqua entre alors dans le lanceur. La même chose est obtenue par une entrée dans le fichier de profil :

installations:
  visit: /home/user/opt/visit

axqua profile init entre automatiquement le lanceur si la commande visit peut être lancée à partir d’un terminal ou si VisIt est installé à /opt.

ParaView

ParaView est adapté pour l’inspection interactive des résultats tridimensionnels.

Les assistants utilisent le paquet ParaView du système d’exploitation, qui est l’un des paquets système énumérés sur l’onglet Check. L’installation nécessite des droits d’administrateur (Logiciel de simulation). Une fois le paquet installé, l’assistant entre le programme /usr/bin/paraview dans le profil sous postprocessors.paraview. Un nouveau ParaView du site Web de ParaView peut être utilisé à la place : le décompresser et sélectionner le dossier décompilé comme l’installation dossier de ParaView dans l’éditeur de profil.

ParaView ouvre un OpenFOAM cas directement. Il ne lit pas le format de résultat de TELEMAC (SELAFIN), et VisIt non plus. aXqua exporte donc TELEMAC produit dans un format que les deux programmes lisent (ParaView).

TELEMAC lui-même est distribué avec le code source d’une extension ParaView qui lit les fichiers SELAFIN (optionals/addons/Paraview_Plugins/SerafinReader dans le dossier TELEMAC). Cette extension doit être compilée pour la version de ParaView en utilisation et n’existe pas pour VisIt. L’exportation d’aXqua n’exige pas.
