Messages d’avertissement

Un avertissement signifie que aXqua a accompli une étape mais a trouvé quelque chose qui peut affecter le résultat. Les avertissements apparaissent dans les fichiers journaux avec le niveau WARNING (Conseils généraux & fichiers journaux). Cette page énumère les avertissements les plus fréquents avec leur signification et leur remède. Les messages sont cités comme ils apparaissent dans le journal, avec ... à la place des valeurs d’un cas particulier.

Note

Les codes uniques pour tous les avertissements, qui lient chaque message à son explication, ne sont pas encore disponibles dans cette version.

Fichier de cas

deprecated config keys ..., still loaded but rename them

Le fichier de cas utilise des entrées d’une ancienne version aXqua. Le cas est lu correctement. Exécutez axqua migrate <case-file> --to-case pour écrire un fichier de cas du type actuel à côté.

using the pre-rename artifact folder hydromate-case/

Le cas a été construit avec une version antérieure, dans laquelle la sortie dossier avait un autre nom. aXqua continue d’utiliser le dossier existant. Renommer le dossier à axqua-case quand aucune tâche de ce cas ne fonctionne.

Prétraitement

BAMG meshing failed (...); retrying with a coarser background metric grid

Le générateur maillage n’a pas réussi avec ses premiers réglages et répète le maillage avec des réglages adaptés. Si aucune erreur ne suit, le maillage est valide et aucune action n’est requise. Si le maillage échoue à plusieurs reprises, la différence entre les longueurs de bord du voisin zones de maillage est trop grande. Augmentez la plus petite longueur de bord ou agrandissez la zone de raffinement.

STABILITY RISK: inflow and outflow are resolved at different node spacings

Le maillage est beaucoup plus fin à une frontière ouverte qu’à l’autre, ce qui peut provoquer une simulation instable. Attribuer les zones de maillage à l’entrée et à la sortie une longueur de bord similaire.

STABILITY RISK: liquid boundaries have ... inflow and ... outflow nodes

Aucun nœuds du maillage n’a été trouvé sur une ligne d’entrée ou de sortie. Vérifier que les lignes se trouvent sur le contour de la zone d’étude et que leur champ type contient inflow ou outflow.

liquid_boundaries ... has no inflow/outflow type column; treating every line as inflow

Le champ couche de lignes n’a pas d’attribut qui identifie les entrées et sorties. Ajouter le champ Type (inflow/outflow) (Frontières liquides).

ground-truth data do not match; skipping HydroBayesCal setup

Le modèle a été construit, mais les tables de mesure du calage n’ont pas été écrites, car les mesures de terrain ne pouvaient pas être lues ou ne correspondaient pas à leur couche de points. La raison suit dans le même message. Corriger les fichiers de mesure et répéter le prétraitement avant de commencer un calage.

finite volumes accept only TURBULENCE MODEL 1 (constant viscosity)

La méthode du volume fini a été sélectionnée avec un autre modèle de turbulence. aXqua utilise plutôt le modèle de viscosité constante. Sélectionnez des éléments finis si un modèle de turbulence est requis (TELEMAC choix).

morphodynamics.enabled but neither bedload nor suspended_load is on

La simulation morphodynamique ne transporterait aucun sédiment. Activer au moins un mode de transport (TELEMAC-GAIA Configuration).

Simulations

fluxes did NOT reach the ... imbalance tolerance within the run

L’écoulement et l’écoulement diffèrent toujours à la fin de la course, de sorte que l’écoulement n’est pas stable. Augmenter hydrodynamics.duration et répéter la course. Si la différence ne diminue plus, vérifiez le niveau d’eau en aval et le rapport de mouillage (TELEMAC à sec 2D/3D).

no hotstart end time; extend the run or relax abs_tolerance

La différence entre les entrées et les sorties n’est pas restée assez longue. Le fichier hotstart, dont le calage a besoin, n’a donc pas été écrit. Augmenter hydrodynamics.duration.

GRACJG: EXCEEDING MAXIMUM ITERATIONS (dans la liste TELEMAC)

Un solveur linéaire de TELEMAC n’a pas établi sa précision dans le nombre autorisé d’itérations. Lors du remplissage d’un tronçon sec, ce message est commun et inoffensif, à condition qu’il disparaisse une fois le tronçon rempli. Si elle persiste jusqu’à la fin de la course, le résultat ne doit pas être utilisé.

no 2D result at ...: the OpenFOAM case will use a flat lid and a cold start

Le modèle OpenFOAM est construit sans échauffement TELEMAC, ce qui augmente considérablement son temps de calcul. Lancez d’abord la simulation TELEMAC stable (aXqua concept d’échauffement).

checkMesh flagged marginal faces (the mesh is still runnable)

Le contrôle maillage d’OpenFOAM a trouvé un petit nombre de cellules de mauvaise qualité, généralement à des pas sur le terrain. La simulation peut être exécutée. Si elle devient instable, augmentez la taille de maille ou lissez le terrain aux endroits signalés.

Vérification d’un cas

La vérification d’un cas (Check sur l’onglet Case Setup, Save dans les paramètres cas, ou axqua check <case-file>) indique les avertissements suivants. L’extension montre chacun d’eux comme un triangle orange à côté du cadre concerné.

the case names no simulation program, so nothing can be built or run

Le fichier de cas ne contient ni un bloc telemac, ni un bloc openfoam. Ajoutez le bloc du programme à utiliser, par exemple avec le commutateur Simulate with TELEMAC sur la page TELEMAC des paramètres cas.

no discharge is set, so the steady simulation has no inflow

Le cas peut être enregistré, mais la prochaine étape du workflow nécessite ce réglage. Entrez le débit sur la page Liquid boundaries des paramètres cas (Frontières liquides).

The files of the validation situation 'High flow' show different discharges; the last one in the table was saved.

Une situation de validation a un débit, et le tableau Measurement files des paramètres cas le montre dans chaque ligne de la situation. Lorsque les lignes affichent encore des valeurs différentes, la dernière dans la table a été enregistrée. Entrez le débit de la situation dans une de ses lignes ; les autres lignes suivent (situation de validation).

Contrôle hydrologique

Le contrôle hydrologique d’un cas en mode hydrologie signale les avertissements suivants (Hydrologie). Un avertissement n’arrête pas la construction.

The rain peaks at ... mm/h

Plus de 150 mm/h sont maintenus par un nuage pendant quelques minutes seulement. La cause habituelle est une série de profondeurs par intervalle qui est lue comme intensités : set hydrology.rainfall_units à mm.

The rain record has no value for ... intervals

Les rangées de la série de pluie sont vides, ou tiennent -999, ce qui fait que le DWD marque une mesure manquante. aXqua garde leurs intervalles et les prend comme secs, de sorte qu’aucune pluie n’est inventée, mais la pluie qui est tombée dans un trou est absente de la simulation. Remplir les trous d’un voisin station hydrométrique ou d’un produit radar, ou s’assurer que l’événement se trouve en dehors d’eux.

The rain comes from a reanalysis (ERA5)

La pluie a été téléchargée depuis Open-Meteo. Une réanalyse répand une tempête sur des cellules de 10 à 30 km et d’une heure et sous-estime de courtes intensités. Utilisez la station hydrométrique ou les données radar de l’agence météorologique nationale où elles existent, ou une tempête de conception.

The rain has no date, the weather does

Une tempête de conception, ou une table de pluie en quelques secondes, n’a pas d’heure de calendrier, tandis que les séries météorologiques ont des dates, par exemple d’un événement que l’assistant de données a téléchargé avant. Le temps est ensuite appliqué dès le début de la pluie, avec son vent et l’évaporation de ses propres jours. Définissez hydrology.rainfall_start à la date et à l’heure où la pluie est censée commencer dans la série météorologique, ou retirez la série météorologique quand elle appartient à un autre événement.

The weather series has no value for ... readings of ...

Les cellules de la série météo sont vides, ou tiennent -999, ce qui indique que le DWD marque une mesure manquante. aXqua interpole chacun d’eux dans le temps entre les lectures avant et après, et la direction du vent comme un angle, parce que le vent, le rayonnement, la température et l’humidité changent progressivement, et une valeur de -999 entrerait autrement dans le vent et l’évaporation comme si elle avait été mesurée. Pendant quelques heures, l’interpolation manque le cours de la journée : combler de plus longues lacunes d’une station voisine, ou s’assurer que l’événement se trouve en dehors d’eux.

The weather ends at ... s, the run at ... s

Après la fin de la série météo, il n’y a ni vent ni évaporation. Étendre la série jusqu’à la fin de la course.

The wind reaches ... m/s at 10 m

Au-dessus de 40 m/s, vérifier l’unité : m/s, pas km/h.

Evaporation reaches ... mm/h

L’eau libre s’évapore rarement plus de 1,5 mm en une heure. Vérifiez l’unité et0 ou evaporation: mm/h, pas mm/jour.

Soil zone ... is ... with Ks = ... mm/h; Rawls et al. (1983) give ...

La conductivité d’une zone diffère de plus d’un facteur de dix de la moyenne de sa classe de texture. Cela peut être juste pour un sol mesuré ; souvent c’est une unité : Ks est en mm/h, et 1 cm/h est 10 mm/h, 1e-6 m/s est 3,6 mm/h.

No initial water content is given

Le sol commence par une saturation efficace de initial_saturation (0.3). Le ruissellement d’une tempête dépend fortement du contenu en eau au début : donner une valeur mesurée, la valeur ERA5-Land de l’événement (assistant de données), ou theta_i par zone.

The case has no outflow line: all rain stays in the catchment

Droit pour une dépression fermée ; sinon tracer une ligne de sortie sur le contour à travers la sortie du bassin (page Liquid boundaries des paramètres cas).

A free outlet holds only where the flow leaves supercritical

Une prise libre ne prescrit rien. À une sortie plus lente, l’eau se remplit dans un étang, ou le noyau à éléments finis devient instable, et le noyau à volumes finis laisse l’eau entrer partout où la vitesse à la ligne de sortie pointe dans le domaine. Utilisez normal_depth sauf si la sortie est raide et lisse, et overfall au bord inférieur d’un champ sur lequel le terrain tombe (Frontières et sortie).

The finite-element kernel lets thin films drain slowly

TELEMAC valide le ruissellement des précipitations avec son noyau à volume fini et la reconstruction hydrostatique de Chen et Noelle (hydrology.kernel: finite-volumes).

The run ends ... s after the rain

L’eau de l’extrémité du bassin versant n’est pas tronçon la sortie avant la fin de la course, de sorte que la récession de l’hydrographe est coupée. Élever hydrology.drain_time.

The mesh will have about ... elements

Plus de deux millions de triangles prennent du temps à calculer. Élever mesh.default_size ou les longueurs de bordure des zones de maillage, et préciser où cela compte.

... % of the catchment drains across the outline where it is a wall

Le contour ne suit pas le fossé de drainage : le terrain descend du domaine sous un mur, et l’eau ramasse les étangs en pente contre lui. Faire ces étirements de lignes de sortie, ou déplacer le contour à la fracture (Frontières et sortie).

The terrain holds ... closed depressions

Une dépression maintient la pluie jusqu’à ce qu’elle soit pleine. C’est bien pour un étang et un mauvais endroit où le modèle de terrain bloque un ponceau ou l’ouverture d’un pont : couper ces ouvertures dans le modèle de terrain, par exemple en tant que structure (Géodonnées).

The terrain model could not be analyzed

L’analyse du terrain a échoué, généralement parce que le modèle de terrain ne couvre pas le contour. La construction elle-même nomme le problème plus en détail.

Profil de cet ordinateur

La vérification du profil (Check sur l’onglet Configuration ou axqua profile check) indique les avertissements suivants. L’extension montre chacun d’eux comme un triangle orange à côté de l’entrée concernée. Un clic sur le triangle ouvre le message. Un avertissement n’empêche pas de sauvegarder le profil.

no environment script is set for ..., so simulations with it cannot be started

Le profil n’indique pas où TELEMAC ou OpenFOAM est installé. Sélectionnez l’installation dossier ou le script environnement de l’installation dans l’éditeur de profil (Définir les liaisons solveur). Laissez les deux entrées vides si le programme n’est pas utilisé sur cet ordinateur.

the installation folder of ... holds several environment scripts ou no environment script of ... was found in the installation folder

Le profil nomme l’installation dossier d’un code de simulation et aucun script d’environnement, et aXqua ne peut pas déterminer le script du dossier. Une installation TELEMAC peut contenir un script d’environnement par configuration du compilateur. Sélectionnez le script d’environnement lui-même dans l’éditeur de profil.

the installation folder of ... does not exist

Le profil désigne un dossier qui n’est pas sur cet ordinateur, par exemple parce que le programme a été déplacé ou supprimé. Sélectionnez à nouveau le dossier dans l’éditeur de profil, ou videz l’entrée. Un programme dont le script d’environnement ou le fichier de programme est entré dans le profil continue de fonctionner.

the environment script of ... is not in the installation folder entered for it ou the program of ... is not in the installation folder entered for it

Les deux entrées d’un programme pointent vers différentes installations. aXqua utilise le script d’environnement ou le fichier de programme, et le dossier n’a aucun effet. Sélectionnez le dossier auquel le fichier appartient ou effacez le dossier.

this version of aXqua does not know the entry ...; it is kept as it is and not used

Le profil contient une entrée que la version installée d’aXqua ne connaît pas. Si une version plus récente de aXqua ou de l’extension a écrit l’entrée, mettre à jour aXqua, et l’entrée prend effet. Si l’entrée est une erreur de saisie dans un profil qui a été modifié à la main, le message nomme l’entrée qui est probablement sensée. Corriger le nom dans le fichier de profil. Les autres entrées du profil sont utilisées dans l’un ou l’autre cas, et l’enregistrement du profil garde l’entrée.

the variables of ... were already set before its environment script ran

La session terminal ou QGIS contenait déjà les paramètres du programme de simulation avant qu’aXqua charge le script d’environnement, généralement parce qu’un fichier de démarrage à l’échelle du système les charge. Une tâche n’hérite pas de ces paramètres. Vérifiez que le script environnement du profil unique configure l’installation, en particulier si plusieurs versions du programme sont installées.

... processes are requested for ..., but this computer has ... logical cores

Plus de processus que les cœurs du processeur ralentissent une simulation. Réduire le nombre de cœurs de processeur dans le profil.

this is OpenFOAM ...; aXqua writes input files for v2406

Le script environnement appartient à une autre version OpenFOAM. aXqua écrit ses fichiers d’entrée pour la version v2406 et d’autres versions peuvent les rejeter. Entrez le script environnement d’OpenFOAM v2406 dans le profil.

Installation du logiciel de simulation

L’onglet Check d’un assistant d’installation, l’onglet Installation d’une installation terminée, et axqua install plan rapportent les avertissements suivants. Une installation peut être lancée avec un avertissement.

... of ... system packages are not installed

L’installation nécessite des paquets du système d’exploitation manquant. Le message les énumère et donne la commande qui les installe, ce qui nécessite des droits d’administrateur. Cliquez sur Install the packages… dans l’assistant, ou copiez la commande dans un terminal, et cliquez sur Check again (Logiciel de simulation). Pour OpenFOAM avec un OpenFOAM v2406 existant, la plupart des paquets listés sont nécessaires uniquement pour compiler OpenFOAM lui-même, et l’installation fonctionne normalement sans eux.

the package sources of this system do not offer: ...

Le système d’exploitation ne connaît pas un paquet pour lequel le nom de l’installateur, généralement parce que le système est plus ancien ou plus récent que celui pour lequel l’installateur a été écrit. L’installation peut encore fonctionner si un autre paquet fournit les mêmes fichiers. Sinon, un administrateur doit ajouter une source de paquets.

the list of system packages could not be read from the installer

aXqua lit la liste des paquets requis à partir du script d’installation et ne l’a pas trouvé dans cette version du script. L’installation peut être démarrée. Il s’arrête avec un message propre si un paquet est manquant.

... GiB are free in ...; the installation needs about ... GiB

Le lecteur de l’installation dossier peut être trop petit. Sélectionnez un dossier sur un disque avec plus d’espace libre sur l’onglet Settings de l’assistant.

... is inside your home folder, which other users usually cannot open

Une installation pour tous les utilisateurs a été donnée un dossier dans votre dossier d’origine. D’autres comptes utilisateurs n’ont généralement pas accès à un dossier d’origine, donc ils ne peuvent pas exécuter les programmes. Sélectionnez un dossier en dehors de celui-ci, comme /opt/openfoam-sediment-v2406.

... exists already ou ... holds an installation of this installer, which is continued

L’installation dossier contient une installation antérieure. L’installateur continue avec : il conserve ce qui est téléchargé et construit le programme à nouveau. Sélectionnez un autre dossier pour laisser l’installation antérieure intacte.

no OpenFOAM v2406 was found on this computer, so it is compiled from its source code

Compiler OpenFOAM prend plusieurs heures et environ 20 Go. Si OpenFOAM v2406 est installé, sélectionnez son fichier etc/bashrc sur l’onglet Settings de l’assistant. Un OpenFOAM v2406 emballé, qu’un administrateur installe en quelques minutes, évite la compilation (Ouvrir).

ParaView is not installed

Les assistants utilisent le paquet ParaView du système d’exploitation, et il n’est pas installé. VisIt est installé tout de même. Installez les paquets système listés sur l’onglet Check, ou entrez un autre ParaView dans l’éditeur de profil (ParaView).

VisIt was not installed, so it was not entered in the profile

OpenFOAM et le sédiment solveurs sont installés et entrés dans le profil, mais l’installateur n’a pas quitté VisIt où aXqua s’y attend. Le logiciel de simulation fonctionne sans VisIt. Installez VisIt seul avec le assistant pour ParaView et VisIt sur l’onglet Configuration, ou avec axqua install start postprocessors (VisIt).

'Download the input files of the example cases' did not complete

TELEMAC est installé et fonctionne, mais les fichiers d’entrée de son exemple cas n’ont pas été téléchargés complètement. Le message cite les dernières lignes du journal d’installation. La cause habituelle est le serveur de téléchargement de TELEMAC, qui refuse d’autres demandes pour un certain temps après de nombreux téléchargements depuis un seul réseau (Rate limit exceeded, error: 429). Répétez le téléchargement plus tard avec la commande que le nom du message, axqua install telemac-examples <folder>. Il ne récupère que les fichiers manquants.

the installation could not be entered in the profile

Le programme est installé, mais le profil de l’ordinateur n’a pas pu être écrit, généralement parce que le profil existant contient une erreur, ou parce qu’une autre installation écrivait le profil au même moment et n’a pas fini. Le message énumère les entrées. Ouvrez l’éditeur de profil sur l’onglet Configuration, corrigez le profil et entrez-les là (Profil d’extension).

Logiciel de simulation

NOTE: already present in the ambient environment

Les variables d’un code de simulation étaient déjà définies dans le terminal avant que aXqua ne lise le script environnement. Une tâche n’hérite pas des paramètres d’une terminal. Vérifiez que la liaison solveur nomme le script d’environnement correct (Définir les liaisons solveur). Sinon, une simulation peut fonctionner à terminal et échouer en tant que tâche.
