Messages d’erreur

Une erreur signifie qu’aXqua n’a pas pu accomplir une étape. Les erreurs apparaissent dans les fichiers journaux avec le niveau ERROR et dans la barre de messages de l’extension (Conseils généraux & fichiers journaux).

Chaque erreur appartient à l’une des cinq catégories. La catégorie détermine où chercher la cause :

Catégorie

Code

Où chercher

Fichier de cas

axqua.config

Une entrée du fichier de cas est manquante, mal orthographiée ou a une valeur non valide.

Géodonnées

axqua.geodata

Une entrée couche ou raster est manquante ou manque une propriété requise.

Logiciel de simulation

axqua.environment

TELEMAC ou OpenFOAM ne peuvent pas être atteints avec les liaisons solveur actuelles.

Simulation

axqua.solver

Le code de simulation a commencé et s’est arrêté avec une erreur. Lisez sa propre sortie.

Maillage

axqua.mesh

Le maillage n’a pas pu être créé ou n’est pas utilisable.

Lorsque aXqua connaît un remède, le message d’erreur le contient. Pour une tâche ratée, l’erreur est stockée avec son code et son remède dans le fichier status.json de la tâche et est montrée sous la liste tâche de l’extension.

Note

Des codes uniques pour les erreurs individuelles dans ces catégories, qui relient chaque message à son explication, ne sont pas encore disponibles dans cette version.

Installation

ModuleNotFoundError: No module named 'axqua'

Le programme aXqua n’est pas installé dans l’environnement Python actif. Activer l’environnement et installer aXqua (Extension de QGIS). Une copie du dépôt seul n’est pas suffisante, car le code source se trouve dans le sous-dossier src/.

ImportError: libjxl.so...: cannot open shared object file

Une bibliothèque système que les paquets géospatials exigent ne correspond pas à leur version. Cela se produit lorsque des colis d’origine différente sont mélangés dans un même environnement. Créer un nouvel environnement qui retient Python seul et y installe aXqua avec pip install axqua (Extension de QGIS), afin que tous les paquets géospatials proviennent de PyPI. Dans une copie du dépôt, environment.yml sert le même but avec les paquets de conda-forge.

axqua could not be found (extension)

L’extension n’a pas trouvé le programme axqua. Le message énumère les trois endroits qui ont été fouillés. Entrez le chemin complet du programme à aXqua > Settings et cliquez sur Test (Extension de QGIS).

Installation du logiciel de simulation

L’onglet Check d’un assistant d’installation, l’onglet Installation d’une installation échouée, et axqua install signaler les erreurs suivantes. Une installation ne peut pas être démarrée avec une erreur de l’onglet Check.

there is no installer for this system

Les scripts d’installation existent pour Debian 12, Ubuntu 22.04, Ubuntu 24.04 et Linux Mint 22, et l’installateur TELEMAC ne couvre pas Ubuntu 22.04. L’installateur OpenFOAM et l’installateur VisIt nécessitent en outre un processeur x86-64. Sur un système construit sur l’un des systèmes pris en charge, sélectionnez le système de base sous Further settings sur l’onglet Settings de l’assistant. Sinon, installez le programme à la main et entrez-le dans l’éditeur de profil (Logiciel de simulation).

TELEMAC and OpenFOAM are installed in the Windows Subsystem for Linux

Les programmes de simulation ne fonctionnent pas dans Windows lui-même. Installez une distribution Linux dans le sous-système Windows pour Linux et démarrez l’installation (Logiciel de simulation).

the installers refuse to run as the user root

Démarrer QGIS ou terminal en tant qu’utilisateur ordinaire. Les droits d’administrateur sont nécessaires uniquement pour les paquets système.

... is a folder of Windows

Dans le sous-système Windows pour Linux, un dossier ci-dessous /mnt/ appartient à Windows. Sélectionnez un dossier dans le système de fichiers Linux, par exemple dans le dossier d’accueil.

the folder ... has a space in its name

Ni TELEMAC ni OpenFOAM ne peuvent être construits dans un dossier dont le chemin contient un espace. Sélectionnez un autre dossier.

... cannot be the folder of an installation for all users

À la fin d’une installation pour tous les utilisateurs, l’ensemble de l’installation dossier est remis à l’administrateur. Un dossier comme /opt ou /usr lui-même, ou votre dossier d’origine, serait remis avec tout ce qu’il contient. Choisissez un dossier propre, comme /opt/telemac.

... exists and you cannot write into it

L’installation du dossier d’une installation pour tous les utilisateurs appartient à quelqu’un d’autre et n’a pas été faite par une installation d’aXqua pour tous les utilisateurs, de sorte qu’aXqua ne la reprend pas. Sélectionnez un dossier qui n’existe pas encore.

... needs the rights of an administrator

Une installation pour tous les utilisateurs a besoin du mot de passe d’un administrateur avant et après la construction, et cette session ne pouvait pas ouvrir la boîte de dialogue de mot de passe du bureau ni demander à terminal. Cela arrive à une installation qui a été démarrée détachée, sans bureau. Commencer par un terminal avec axqua install start <program> --for-all-users --foreground, ou faire exécuter par un administrateur la commande que le nom du message et recommencer l’installation. Rien n’a été construit à ce stade.

... exists and was not made by this installer

L’installateur OpenFOAM installe dans un nouveau dossier ou poursuit une installation propre. Sélectionnez un dossier qui n’existe pas encore.

... holds an installation made by another version of the installer or against another OpenFOAM

L’installateur OpenFOAM continue seulement ce que la même version a commencé avec le même OpenFOAM. Ouvrez l’assistant avec Install OpenFOAM…, répondez Yes à la question de savoir s’il faut installer à nouveau et sélectionnez Remove the existing installation and install it again in its folder, ou sélectionnez un nouveau dossier.

there is no earlier installation to remove: ...

Remove the existing installation a été sélectionné pour un dossier qui ne détient aucune installation qu’un installateur de aXqua fait. aXqua ne supprime que ces installations. Sélectionnez le dossier de l’installation existante, ou installez-le dans un nouveau dossier.

the SALOME archive ... does not exist ou the OpenFOAM environment script ... does not exist

Un fichier sélectionné sur l’onglet Settings de l’assistant n’est pas sur cet ordinateur. Sélectionnez-le à nouveau ou videz-le.

... belongs to OpenFOAM release ...

Le transport des sédiments solveurs sont construits pour OpenFOAM v2406 et l’installation sélectionnée est une autre version. Sélectionnez le fichier etc/bashrc d’OpenFOAM v2406 ou laissez le assistant compiler OpenFOAM.

the installer scripts could not be downloaded

aXqua télécharge les scripts d’installation TELEMAC avant qu’il ne vérifie l’ordinateur et n’a pas tronçon le dépôt. L’installateur OpenFOAM et le code source d’Olsen solveurs sont envoyés avec aXqua et ne sont pas téléchargés. Vérifier la connexion Internet. Pour un ordinateur sans connexion, copiez le dépôt d’installation et sélectionnez son dossier sous Further settings (dans un terminal: la variable d’environnement AXQUA_INSTALLERS).

the OpenFOAM installer does not run with any Python on this computer

L’installateur OpenFOAM nécessite un Python plus récent que celui qui exécute aXqua, et aXqua n’en a trouvé aucun plus récent. Installez Python 3.12 ou plus récent, par exemple avec Miniforge, et installez aXqua avec.

'...' ended with an error

Une étape de l’installation a échoué. Le message cite les dernières lignes du journal d’installation, qui nomment normalement la cause, et indique l’emplacement du journal complet. Les causes typiques sont un paquet système manquant, un téléchargement interrompu et un lecteur complet. Corriger la cause et recommencer l’installation avec le même dossier : l’installateur continue avec ce qui est déjà téléchargé et construit.

Les lignes remote: Retry later et error: 429 signifient que le serveur de téléchargement de TELEMAC refuse temporairement d’autres demandes, ce qui se produit après de nombreux téléchargements d’un réseau en peu de temps. Attendez quelques minutes et redémarrez l’installation.

the installer finished, but did not produce ...

L’installateur a signalé un succès, mais un programme qu’il aurait dû construire est manquant, donc la construction a échoué en partie. Recherchez le journal d’installation pour la première ligne qui contient Error.

the program this installation enters in the profile is not on this computer

L’installation consiste en un paquet du système d’exploitation, et le paquet n’est pas installé. Installez les paquets système que l’onglet Check des listes assistant, puis redémarrez l’installation.

without VisIt, this installation is the system package of ParaView alone, which is not installed yet

Avec la sélection ParaView only, l’installation des postprocesseurs ne télécharge rien : ParaView est un paquet du système d’exploitation, et l’assistant ne l’entre que dans le profil. Installez les paquets système que l’onglet Check listes, qui nécessite des droits d’administrateur, et cliquez sur Check again (ParaView).

the installation ended without a result

Le processus d’installation a disparu, généralement parce que l’ordinateur a été redémarré ou que l’utilisateur a été déconnecté. Recommencer l’installation avec le même dossier.

Vérification d’un cas

La vérification d’un cas (Check sur l’onglet Case Setup, Save dans les paramètres cas, ou axqua check <case-file>) signale les erreurs suivantes. L’extension montre chacun d’eux comme un triangle rouge foncé à côté du réglage concerné. Une erreur n’empêche pas d’enregistrer le cas, mais le modèle ne peut être construit tant qu’il n’est pas corrigé.

... is required ou ... is not set

Un réglage dont chaque cas a besoin est vide, par exemple le modèle de terrain, le contour du modèle, ou les lignes d’entrée et de sortie. Sélectionnez le fichier dans les paramètres cas (Open case settings… sur l’onglet Case Setup).

the file of ... does not exist

Le fichier de cas nomme un fichier qui n’est pas à l’endroit indiqué. Un chemin qui ne commence pas à la racine du lecteur est lu par rapport au dossier du fichier de cas. Sélectionnez à nouveau le fichier dans les paramètres cas.

... is not a setting of a case ou ... is not a block of a case file

Le fichier de cas contient un nom que aXqua ne connaît pas, dans la plupart des cas à cause d’une erreur de saisie. Le message propose le nom qui était probablement voulu. Corriger le nom dans le fichier de cas avec un éditeur de texte.

the case file is not valid YAML

La structure du fichier est endommagée, par exemple par un côlon manquant ou une indentation incorrecte. Le message désigne la ligne. Corriger avec un éditeur de texte. Les paramètres cas conservent l’original d’un fichier de cas comme <name>.bak la première fois qu’il économise.

the file does not contain the blocks of a case

Le fichier est valide YAML mais pas un fichier de cas, par exemple une liste. Sélectionnez le bon fichier.

the case file cannot be read

Le fichier n’existe pas ou peut ne pas être lu. Vérifier le chemin et les droits d’accès.

Contrôle hydrologique

La vérification en hydrologie d’un cas en mode hydrologie (Check sur le sous-tab Simulations > Hydrology et sur l’onglet Preprocessing, axqua hydrology check <case-file>, et le début de chaque construction) signale les erreurs suivantes. Une erreur arrête la construction (Hydrologie).

The rain series cannot be read ou is not usable

Le fichier de hydrology.rainfall est manquant, n’a pas de colonne de temps, ou a des temps qui n’augmentent pas, intervalles qui se chevauchent, ou pluie négative. Un tableau du temps et de la pluie, en mm/h ou en mm par intervalle, est attendu ; l’assistant de données en écrit un extrait.

The weather series cannot be used

Le vent ou l’évaporation est activé, mais hydrology.weather manque ou manque les colonnes dont le choix a besoin : le vent a besoin wind_speed_10m et wind_direction_10m, l’évaporation et0 needs et0, penman a besoin de rayonnement, de température, d’humidité et de vent avec des dates, et series needs evaporation.

Soil zone ... ou The soil cannot be read

Une valeur de la table du sol est impossible (un K négatif, une tête d’aspiration supérieure à 1 m, qui est habituellement une valeur en centimètres, ou une teneur en eau au début au-dessus de la saturation), une classe de texture est inconnue, ou un nombre de zone de la couche du sol est absent de la table.

Profil de cet ordinateur

La vérification du profil (Check sur l’onglet Configuration, ou axqua profile check) signale les erreurs suivantes. L’extension montre chacun d’eux comme un triangle rouge foncé à côté de l’entrée concernée. Une erreur n’empêche pas l’enregistrement du profil, mais la fonction qui dépend de l’entrée ne fonctionne pas avant que l’entrée soit corrigée.

the ... does not exist, the ... launcher ... is not executable ou the ... program was not found in the installation folder ...

Le profil nomme un fichier de programme qui n’est pas sur cet ordinateur, ou qui ne peut pas être démarré, ou il nomme un dossier d’installation qui ne contient pas le programme. Sélectionnez à nouveau le fichier dans l’éditeur de profil.

the environment script of ... does not exist

Le profil nomme un script d’environnement qui n’est pas sur cet ordinateur. Sélectionnez le script de l’installation (Définir les liaisons solveur).

... cannot be reached

aXqua a chargé le script environnement et n’a pas pu démarrer le programme de simulation. Le message indique ce qui manque. Vérifiez dans un terminal que l’installation fonctionne par elle-même, et que le profil nomme le script environnement de cette installation.

the job root ... cannot be written to

aXqua ne peut pas créer de fichiers dans le dossier pour tâches. Sélectionnez un dossier sur un lecteur avec accès écrit et suffisamment d’espace libre.

the launcher must be one of ..., the number of processes must be at least 1 et similaires

Une entrée du profil a une valeur qui n’est pas possible. Le message désigne l’entrée et les valeurs autorisées.

Fichier de cas

... unknown config keys [...]

Un bloc du fichier de cas contient une entrée que aXqua ne connaît pas, généralement à cause d’une erreur de saisie. Le message désigne le bloc et l’entrée. Comparez l’orthographe avec le modèle commenté du dépôt.

telemac.pysource is not set ou TELEMAC pysource script not found

aXqua ne sait pas où TELEMAC est installé, ou le script d’environnement indiqué n’existe pas. Créer le profil de l’ordinateur avec axqua profile init, ou corriger sa liaison pour TELEMAC (Définir les liaisons solveur).

outflow_condition: elevation requires boundaries.prescribed_elevation

La frontière de sortie est réglée sur une cote de la surface libre, mais aucune élévation n’est donnée. Entrez boundaries.prescribed_elevation, ou sélectionnez une autre condition de sortie (Frontières liquides).

initialization.prewet_depth needs geodata.mesh_zones

Le début préhumide remplit les zones de chenal avec de l’eau et nécessite donc une couche zone de maillage avec une zone dont le nom contient channel (Conditions initiales).

morphodynamics.enabled but no geodata.dem_target / dem_of_difference provided

Une morphodynamique cas nécessite le changement de lit mesuré comme référence. Entrez un deuxième modèle de terrain ou un MNT de différence (Simulation morphodynamique).

Prétraitement et simulation

BAMG failed ou Fatal error in the meshgenerator

Le générateur maillage ne pouvait pas créer le maillage, aussi après avoir répété la tentative avec des paramètres adaptés. Les longueurs de bord du voisin zones de maillage diffèrent trop fortement. Augmenter la plus petite longueur de bord ou agrandir la zone de raffinement, de sorte que la taille du triangle puisse changer progressivement.

TELEMAC s’arrête au premier pas de temps avec un message de la sous-routine DEBIMP

Le profil en travers d’entrée est sec, de sorte que TELEMAC ne peut pas distribuer le débit dessus. Vérifiez que la ligne d’entrée se trouve dans le chenal et que la hauteur d’eau du tronçon rempli à l’entrée (initialization.dry_start_depth) couvre le lit le long de la ligne entière.

TELEMAC-2D stopped the run ... because a value left its limits

La hauteur d’eau ou un composant de vitesse a laissé la plage que le mot clé LIMIT VALUES du fichier de paramètres permet, soit 1000 m/s pour la vitesse. Une telle valeur est une instabilité numérique et non un flux. TELEMAC-2D se termine par une telle course sans code d’erreur, donc aXqua lit l’arrêt de la liste et marque la tâche comme FAILED. Le message indique la quantité, sa valeur, les coordonnées du nœud du maillage et le temps simulé. Inspectez le maillage, la cote du fond et la hauteur d’eau initiale à ces coordonnées en QGIS. Les causes communes sont un évier ou une frontière ouverte sur des cellules qui sont presque sèches, une surface libre initiale qui est loin de la normale, et un pas de temps qui est trop grand (hydrodynamics.desired_courant). Les lignes d’échange internes qui sont appliquées en tant que régions sources à taux fixe (boundaries.internal_sources: true) peuvent provoquer cet arrêt au premier pas de temps, parce que le débit est ensuite retiré d’une bande étroite indépendamment de la hauteur d’eau. Utilisez plutôt le bloc gain_lose, ce qui limite le retrait par la hauteur d’eau (TELEMAC choix).

RIGID LID DOES NOT APPLY HERE

La surface libre du TELEMAC se traduit par des chutes d’étapes qui dépassent la hauteur d’eau locale, par exemple aux fentes d’un passe-poissons. Un couvercle fixe ne peut représenter une telle surface libre. Utilisez openfoam.mode: vof pour ce cas (Choix OpenFOAM).

Tâches

Une tâche échoue immédiatement après son départ

Dans la plupart des cas, le logiciel de simulation ne peut être atteint depuis la tâche. Lisez runner.log de la tâche et vérifiez le profil avec axqua profile check (Définir les liaisons solveur). Notez l’avertissement concernant l’environnement ambiant (Messages d’avertissement) : une tâche n’hérite pas des paramètres de la terminal ou de QGIS.

the 'systemd' launcher is not available on this machine

Les services utilisateurs Linux qu’aXqua utilise par défaut ne sont pas disponibles, ce qui est typique pour certaines sessions distantes. Soumettez la tâche avec l’option --launcher posix, ou sélectionnez posix sous How jobs are detached dans l’éditeur de profil de l’extension (Configuration onglet).

Une tâche reste dans l’état RUNNING bien que rien n’est calculé

Interrogez l’État avec axqua status <job-id> ou cliquez sur Refresh sous la liste tâche. aXqua vérifie ensuite si le processus existe encore et marque la tâche comme FAILED si ce n’est pas le cas, par exemple après un redémarrage de l’ordinateur. La tâche peut être soumise à nouveau.

Extension

aXqua est absent de la liste des extensions installées

QGIS liste une extension seulement s’il peut lire le fichier metadata.txt dans le dossier d’extension, et il saute une extension avec un fichier illisible sans message. Exécutez python scripts/build_plugin_zip.py --check dans le dépôt, qui lit le fichier de la même manière que QGIS et rapporte la ligne qui ne peut pas être lue.

Les onglets du workflow n’affichent que la note pour ajouter un cas

Aucun cas n’est sélectionné, ou le fichier de cas n’a pu être lu. Ajoutez un cas sur l’onglet Case Setup. Si les onglets restent vides, lancez axqua case-status <case-file> --no-write dans un terminal pour obtenir le message d’erreur.

Un résultat couche est chargé sans couleurs

Le nom d’une variable de résultat diffère de celui attendu. Le fichier est intact. Assignez le style dans les propriétés QGIS couche.
